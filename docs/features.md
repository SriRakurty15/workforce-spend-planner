# Features

- **Input**: form entry, paste-from-spreadsheet, and file upload, all through one validator with a row-by-row preview (valid / error / duplicate / will-overwrite).
- **Reports**: computed views of targets vs actuals, headcount vs target, pipeline projection, cost per head, and allocation with hold-back.
- **Analytics**: charts and trend forecasting with confidence bands.
- **Dashboard**: KPI tiles, spend by category, headcount by team.
- **Point-in-time views**: query data `asOf` a past date using the audit history.
- **AI agent**: ask questions in plain English; answers come from live data via tools.
- **Audit log**: every change recorded with before/after values.
